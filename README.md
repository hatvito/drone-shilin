# 台北士林・無人機千棟都會避障挑戰賽 (模組化架構版)

本專案為無人機三維都會低空避障挑戰賽模擬器，100% 精準還原台北市士林區、北士科園區與外雙溪真實地理坐標，包含 1,200+ 棟具備台灣特色（步登老公寓、二丁掛、洗石子、頂樓鐵皮加蓋、水塔）之建築物，並搭載士林高商完整 12 棟校舍、兒童新樂園動態摩天輪、台北捷運淡水信義線動態列車與地面車流。

## 🚀 旗艦版特色與新增增強功能

1. **模組完全解耦**：所有功能按職責分門別類，檔名直觀，修改特定功能（如調整光達射線、修改特定路段或建築外觀）只需修改對應小檔。
2. **免依賴與跨域相容**：採用安全的 `window.ShilinDrone` 命名空間，直接在 Windows 本機雙擊 `index.html`（`file://`）即可離線執行，無 CORS 跨域錯誤。
3. **新增 📡 即時光達射線視覺化**：點擊頂部「光達射線」按鈕，可於 3D 場景中直接看見無人機發射的 16 向虛擬雷射，近距遇障變紅，大幅降低演算法除錯門檻。
4. **新增 ⏩ 1x / 2x / 4x 模擬倍速切換**：在代碼編輯區頂部可快速切換模擬步進速度，測試長途飛行更省時。
5. **新增 🔊 原生 Web Audio 音效**：無需外部音訊檔案，內建合成四軸馬達蜂鳴、近距防撞警報聲、撞牆失事悶響與達成目標之勝利音效。
6. **低空巷戰防作弊限高機制**：空域嚴格限制於 `0 ~ 25.0 公尺`，無人機必須在真實樓宇巷弄中穿梭，禁止高空直飛。
7. **滑鼠左右鍵操作互換**：左鍵拖曳平移視野（Pan），右鍵拖曳旋轉環視（Orbit/Rotate），滾輪縮放（Zoom），單擊建築檢視屬性。
8. **Google Map 街圖極致擬真單棟多邊形輪廓建築群 (2,260+ 棟)**：以 `map_shilin.png` 高解析街圖為基準，利用距離變換 (Distance Transform) 與分水嶺演算法 (Watershed) 精準切分密集連棟街屋，並以道格拉斯-普克演算法 (Ramer-Douglas-Peucker) 萃取單棟真實 2D 多邊形頂點輪廓（包含凸凹、L/T型、梯形、削角），並以 `THREE.ExtrudeGeometry` 原生擠壓成形。
9. **豐富台灣在地街景隨機建築樣式**：
   - 多元立面材質：老灰石洗石子、暖色二丁掛、粉紅馬賽克、清水紅磚、青苔綠磚、純白磁磚、70年代焦糖長條磚、老士林水磨石子、一樓臨路騎樓商鋪招牌看板、北士科消光鋁板與玻璃帷幕摩天商辦。
   - 擬真屋頂五彩加蓋與設備：六色經典浪板（台綠、深綠、亮藍、酒紅、鍍鋅銀、草綠）、電梯機房與不銹鋼雙併立式/臥式水塔。
   - 齒狀天際線高低差：相鄰街屋依建造年代隨機產生不同層數與高度（8m~42m），忠實呈現台灣都會巷弄高低錯落的空域挑戰。
10. **GPU InstancedMesh 零負擔合批優化**：數千座屋頂鐵皮加蓋與水塔全面採用合批實例化渲染（僅耗費 7 個 Draw Calls），即便場景容納超過 2,260 棟多邊形立體建築與實體物理包圍盒，仍能穩定維持 60 FPS 流暢度。
11. **Scratch 積木圖形化拖拉編程版 (`blockly.html`)**：整合 Google Blockly 深色主題畫布，學生無需手打 JavaScript，即可透過直覺的中文方塊拼裝巡航速度、高度鎖定、16向光達環周排斥力場、危急減速與方向偏轉，並支援即時編譯與「查看/複製 JavaScript 代碼」。
12. **大視窗全螢幕代碼編輯器 (`#code-modal`)**：代碼版 (`index.html`) 具備一鍵展開全螢幕編輯器彈窗，支援 Tab 鍵縮排、`Ctrl+Enter` 立即起飛、常用避障演算法片段快速插入與動態字級放大縮小，大幅改善側邊欄閱讀體驗。
13. **任務指揮中心關卡系統 (`missions.html`)**：
    - 提供 6 大特種戰術關卡：晴空直線飆速、巷弄穿堂側風、斜頂違建與水塔迷宮、高空電纜與電線桿、濃霧與低空飛鳥群、無盡自由沙盒。
    - 支援「🧩 積木出征」與「💻 代碼出征」一鍵帶參啟動 (`?mission=...`)。
14. **動態 3D 特種環境障礙生成器 (`mission-hazards.js`)**：
    - 體積濃霧 (`scene.fog`)：遮蔽遠方視距，考驗近距主動光達與都卜勒雷達。
    - 街道電線桿與懸空 3D 電纜：自訂物理碰撞包圍盒，嚴防低空高速掛勾失事。
    - 18° 傾斜鐵皮屋頂：著陸角度判斷，未修正坡度即迫降將導致翻覆側翻墜樓。
    - 低空拍翅飛鳥群：沿街道兩側低空盤旋之動態障礙物。
    - 穿堂側風物理推力：文林路與美崙街風口週期性風切推移無人機。
15. **真實航太 SWaP 電池動力約束**：
    - 動態電池電量衰減（0% 立即迫降失事）。
    - 負重上限限制（防止過度盲目配置全部感測器），訓練真實工程權衡思維。
16. **Firebase 雲端即時排行榜與 3D 霓虹幽靈領跑車 (`leaderboard.js` & `ghost-drone.js`)**：
    - 跨設備即時記錄各考題種子碼之全場前十傑成績與平均航速。
    - 首名完賽者之 3D 飛行軌跡將自動被捕捉並於場景中投射為半透明霓虹幽靈車，同場伴飛示範！
